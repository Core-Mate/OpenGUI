## 工作台 UI 排查清单

范围：工作台、设备列表与详情、任务详情与历史、模型设置、连接指南、未知路由。Artemis 的全局页面切换仅用于结构对照，不复制其视觉或源码。

| 问题 | 位置 | 处理 |
| --- | --- | --- |
| 顶栏与首页面包屑重复 | 工作台 | 顶栏统一为工作台、设备、任务、模型设置；页面不再放首页面包屑。 |
| 「连接设备」实际打开指南且重复导航 | 工作台实时画面区 | 删除入口；设备统一从顶栏进入。 |
| 示例上的外链箭头暗示跳转，但实际只填入任务 | 工作台示例 | 删除箭头，按钮的无障碍名称明确「填入任务示例」。 |
| 自动视频连接时露出过程文案 | 设备卡、设备详情 | 已连接设备自动加载画面，等待期间不显示连接文案；断开、待授权仍显示真实状态。 |
| 任务名称与「查看」指向同一记录 | 任务历史 | 保留任务名称单一入口，状态和停止操作不变。 |
| 模型配置入口被当作任务提交 | 工作台表单 | 独立的 `type="button"` 打开模型设置，空任务不触发校验。 |
| 「视觉模型」等术语与重复标题 | 模型设置 | 统一「模型」，删除重复的二级标题。 |
| 连接指南混入任务教程，返回位置错误 | 连接指南 | 仅列模拟器与 USB 手机两种连接方式，返回设备页。 |
| 页脚指南重复、`shared` 与 `Token` 暴露内部概念 | 全局、任务详情 | 移除重复页脚；共享服务不显示内部名称，用「模型用量」展示统计。 |
| 未知路由提示「记录不存在」 | 未知页面 | 改为「页面不存在」，返回工作台。 |

验收：浏览器端到端覆盖导航、配置入口、设备画面、任务历史和连接指南；实际安装服务在 1280px 与 375px 宽度逐页检查。
