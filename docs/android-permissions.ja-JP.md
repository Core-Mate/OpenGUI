# Android 権限設定ガイド

OpenGUI に root 権限やブートローダーのアンロックは不要です。ただし、画面の取得、アクセシビリティジェスチャーの実行、他のアプリ上へのタスク操作表示のために、いくつかの Android システム権限が必要です。

このガイドは Android 11（API 30）以降を対象としています。これは現在のスクリーンショットベースの実行パスがサポートする最小バージョンです。

権限名と設定場所は端末メーカーによって異なります。以下のパスは検索の手掛かりとして使用し、すべての OS バージョンで同一の固定パスとは考えないでください。

## 権限チェックリスト

最初のタスクを実行する前に、次の 4 項目を完了してください。

- [ ] 端末上で、OpenGUI を実行するコンピューターからの USB デバッグ接続を許可する。
- [ ] アクセシビリティで **OpenGUI AI Automation Service (required)** を有効にする。
- [ ] OpenGUI に「他のアプリの上に表示」権限を許可する。
- [ ] OpenGUI をバッテリー最適化の対象外にする。

USB デバッグは APK のインストールと `adb reverse` に使用されます。残りの 3 項目は、タスク実行前に Android クライアントが確認します。

アクセシビリティとオーバーレイは強い権限です。信頼できる OpenGUI ビルドにのみ許可してください。これらの権限により、アプリは表示中の画面を読み取り、他のアプリを操作し、その上にコントロールを表示できます。

## Android メーカーごとの一般的な名称

実際の名称は、端末モデル、Android バージョン、メーカー OS、システム言語によって異なります。

| システム | アクセシビリティ | オーバーレイ | バッテリー設定 |
| --- | --- | --- | --- |
| Android / Pixel | 「ユーザー補助」。サービスは「ダウンロードしたアプリ」に表示される場合があります | 「他のアプリの上に表示」 | 「制限なし」または「最適化しない」 |
| OPPO / ColorOS | [Issue #41](https://github.com/Core-Mate/OpenGUI/issues/41) では「補助機能」と報告されています。バージョンによっては「ユーザー補助」です | Issue #41 では「他のアプリの上に表示を許可」と報告されています。バージョンによっては「フローティングウィンドウ」です | OpenGUI から開いたバッテリー設定を使用してください。名称は ColorOS のバージョンによって異なります |
| Samsung / One UI | 「ユーザー補助」 > 「インストール済みアプリ」 | 「最前面に表示」（Appear on top） | OpenGUI から開いたバッテリー設定を使用してください。名称は One UI のバージョンによって異なります |
| Xiaomi / HyperOS / MIUI | 「ユーザー補助」は「追加設定」にある場合があります | 名称はバージョンによって異なります。OpenGUI のオーバーレイ設定リンクを使うか、「フローティングウィンドウ」を検索してください | 「バッテリー」 > OpenGUI > 「制限なし」 |
| その他のメーカー OS | 「ユーザー補助」「補助機能」または OpenGUI のサービス名を検索します | 「他のアプリの上に表示」「最前面に表示」「フローティングウィンドウ」を検索します | 「バッテリー最適化」または「制限なし」を検索します |

端末上のパスが一致しない場合は、設定で `OpenGUI`、`ユーザー補助`、`他のアプリの上に表示`、`フローティングウィンドウ`、`バッテリー最適化` を検索してください。

## 設定手順

### 1. USB デバッグを許可する

ローカルバックエンドを使用する場合は、端末をコンピューターに接続し、端末上の USB デバッグ確認を許可します。ADB の状態が `unauthorized` ではなく `device` であることを確認してください。

```bash
adb devices
adb reverse tcp:7777 tcp:7777
```

### 2. ユーザー補助サービスを有効にする

OpenGUI を開き、不足しているユーザー補助権限の項目をタップします。Android のユーザー補助設定で **OpenGUI AI Automation Service (required)** を選択して有効にします。

Android 13 以降では、サイドロードした APK に **制限付き設定** が表示される場合があります。このリポジトリからビルドした APK を信頼できる場合は、**アプリ情報 > その他 > 制限付き設定を許可** を開き、その後ユーザー補助設定に戻ってサービスを有効にします。

### 3. 他のアプリの上に表示することを許可する

OpenGUI に戻ってオーバーレイ権限の項目をタップします。OpenGUI のシステム設定ページで「他のアプリの上に表示」「最前面に表示」「フローティングウィンドウ」または端末で同等のスイッチを有効にします。

### 4. OpenGUI をバッテリー最適化の対象外にする

バッテリー権限の項目をタップし、OpenGUI のバッテリー最適化を無効にするか、「制限なし」を選択します。現在のクライアントは、タスク実行前の権限チェックにこの設定を含めています。

### 5. 結果を確認する

OpenGUI に戻ってタスクを再度開始します。権限不足のダイアログが表示されず、実行中にフローティング操作画面の表示、スクリーンショット取得、ユーザー補助操作が行えることを確認します。

## トラブルシューティング

- **サービスを有効にしても OpenGUI が不足と表示する:** サービスを一度無効にしてから再度有効にし、OpenGUI を再起動します。
- **ユーザー補助のスイッチを操作できない:** サイドロード APK に対する「制限付き設定」の警告を確認します。
- **同じ名前のオーバーレイ画面が見つからない:** 設定で `OpenGUI` を検索し、「特別なアプリアクセス」「アプリ管理」「その他の権限」を確認します。
- **画面ロックまたはバックグラウンド移行後にタスクが停止する:** バッテリーモードが「制限なし」であり、メーカー独自のバックグラウンド動作制御でも OpenGUI が許可されていることを確認します。
- **ADB が `unauthorized` と表示する:** ケーブルを接続し直し、端末上でコンピューターを許可します。確認画面が出ない場合は、以前の USB デバッグ認証を取り消して再試行します。

## スクリーンショットとバージョン差異

権限画面は頻繁に変更されます。スクリーンショットを追加する場合は、端末メーカー、モデル、Android バージョン、メーカー OS バージョン、システム言語を併記してください。スクリーンショットだけに依存せず、検索可能な権限名も残してください。
