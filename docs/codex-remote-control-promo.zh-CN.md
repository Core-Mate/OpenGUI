# 用自然语言控制你的 Android 手机

把任务扔给 OpenGUI，AI 在你的真实手机上帮你执行。打开 App、滚动页面、读内容、处理弹窗。

## 能做什么

- 自然语言下任务，AI 在真机上跑
- 任务最长 12 小时，中途可暂停、恢复、取消
- 远程下发：飞书、Telegram、Discord、REST API 都可以
- 模型自选：Claude Opus、千问 3.6 Plus、豆包 Pro，或接自己的 API

## 为什么不一样

不点坐标。OpenGUI 在手机上跑 VLM，实时看屏幕理解状态，决定下一步。弹窗、加载、登录失效自己处理，不用守旁边。

## 快速开始

扔给 Claude 或 Codex：

```
读一下 ./skills/open-gui-bootstrap/SKILL.md，然后帮我把 OpenGUI 跑起来，只在必须时告诉我手机上要做什么。
```
