# 用自然语言控制你的 Android 手机

把任务扔给 OpenGUI，AI 在你的真实手机上帮你执行。打开 App、滚动页面、读内容、处理弹窗——都可以。

## 能做什么

- 用自然语言下达任务，AI 在真机上执行
- 任务持续最长 12 小时，中途可暂停、恢复、取消
- 远程下发：通过飞书、Telegram、Discord 或 REST API 把任务发给手机
- 模型自选：Claude Opus、千问 3.6 Plus、豆包 Pro，或接入自己的 API

## 为什么不一样

不点坐标。OpenGUI 在手机上跑 VLM，实时看屏幕理解状态，决定下一步做什么。遇到弹窗、加载、登录失效自己处理，不需要守在旁边。
