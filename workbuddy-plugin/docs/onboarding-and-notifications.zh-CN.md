# 安装后使用与通知验收

## 用户看到的流程

1. 安装器显示“配置已写入”及下一步；这不代表宿主已加载。打开 WorkBuddy，核对并启用 OpenGUI MCP，在 `/hooks`、`/skills` 检查安装项。当前聊天未刷新时新建聊天。
2. 发送 `@opengui`，右侧打开任务首页。登录，选择执行模型，连接已授权的 Android 手机或启动模拟器；设备未出现时按连接帮助处理并重新检测。
3. 从“场景示例”选择“设置与返回桌面”，点击“填入任务”。检查内容后点击“开始执行”；填入示例、设备预览和打开首页都不启动操作。
4. 执行进度、内容审核和接管提示在右侧展示。审核“跳过此条”只跳过当前内容，不发送；任务继续由执行模型按原目标处理。接管后点击“恢复控制”，执行器重新观察再继续。
5. 结束后在工作台查看结论和报告，点击“新建任务”回到空白任务输入框。聊天发起的任务还会返回可用的报告链接。

## 左侧如何获取进度

左侧不读取右侧网页 DOM、不截图网页、不通过 HTTP 或 shell 轮询看板。插件内部在已保存的状态变化后触发事件。

- 宿主为工具调用提供 `progressToken` 时，使用标准 MCP `notifications/progress`，经原请求的 broker 连接回传。一个 `opengui_execute` 等待可跨越步骤、审核和接管，直到结束或最长十分钟到期。通知不包含截图、账号、目标链接或审核草稿。
- 无进度支持时，同一个执行工具等待下一次有意义的状态变化；已返回过的审核状态不会立即重复返回。超时续等保持安静，不重复“仍在等待”。
- 首帧与人工决定也使用状态事件唤醒，取消或请求结束后清理监听器。超时只是等待到期，不代表执行失败；连接断开和宿主终止仍遵守原控制权生命周期。
- MCP 进度通知仅属于正在进行的工具调用，不能据此承诺唤醒已结束的聊天。由独立首页启动的任务应在右侧查看进展。

依据：[MCP Progress](https://modelcontextprotocol.io/specification/2025-11-25/basic/utilities/progress)。本机 WorkBuddy 5.6.2 的随包引擎可转发 `onProgress` 到 MCP SDK；实际桌面的工具卡呈现仍需原生任务验收。

另检查了 [CodeBuddy Channels（Beta）](https://www.codebuddy.ai/docs/cli/channels-reference)：支持主动注入聊天事件，但本机引擎使用当前聊天上下文，未确认原任务的定向投递及桌面唤醒契约。本轮不启用全局 Channel，不把任意当前聊天当作原任务。

## 用例准备

通用安装、首页、首帧、通知隔离、审核跳过和接管恢复可以用本地测试设备与模拟模型验证，无需提供真实业务账号。

真实 App 验收需要以下资料；缺失项应先确认，不能猜测预期或把环境问题记成产品缺陷：

| 场景 | 需要准备 | 关键验收 |
| --- | --- | --- |
| App 功能测试 | 应用名/包名或本地 APK、版本、入口页面、步骤、测试输入、预期结果、停止位置 | 逐步核验；停在约定位置；报告保留证据和未测项 |
| 评论审核 | 平台及已登录账号、目标链接、评论范围、语气/约束、数量或时限 | 批准、修改、跳过各一次；跳过不发送且后续可继续；结果不确定不重发 |
| 接管恢复 | 可复现登录/权限页面或人工接管步骤 | 接管期间无截图/动作/推理；恢复后新观察，不重放旧动作 |
| 原生通知 | WorkBuddy 中一条独立测试任务，包含等待审核或接管 | 左侧没有网页轮询；同一状态不刷屏；另一聊天收不到该任务进度；结束仅汇总一次 |

不要在用例文档或聊天中提供密码、验证码、密钥。登录由用户在设备或账号面板完成。允许真实发布的目标与数量应明确；否则验证到提交前停止。

## 本轮验证（2026-10-06）

- 61 个测试文件、477 项测试通过；构建、发布契约、全新/离线安装烟测通过。覆盖通知按请求隔离、通知不提前结束工具、无订阅时兼容回退、审核未变化不反复返回、跳过后继续、取消清理和快速交还时丢弃旧动作批次。
- 在本地隔离工作台验证 1280×720 与 390×844：打开示例 → 填入任务（未执行）→ 开始 → 首帧 → 模拟执行受阻报告 → 新建空任务。无横向溢出、无控制台 error/warn；未操作真实手机业务。
- 实际 WorkBuddy 5.6.2 已安装归档 `c475baa5e2db8988655a6d0bd827b20192e9173569f1ddf17bb0de381b6b85c7`，重开桌面后右侧新版首页及实时设备预览可见。8 个关键安装模块与构建一致，禁止网页轮询的 Skill 已安装；安装包 MCP 的只读设备发现通过。
- 实际随包 headless 引擎在隔离配置下加载 25 项工具，零模型提示词/手机工具调用。这不等同于真实宿主模型任务验收。桌面内完整通知展示、真实 App 测试和真实发布仍按上表准备与验收。
