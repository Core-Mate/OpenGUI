# 从 GitHub 安装 OpenGUI 到 WorkBuddy

完整安装说明已合并到[根 README 的 WorkBuddy 安装部分](../../README.zh-CN.md#workbuddy-安装)：下载安装脚本 → 在 macOS 终端运行 → 在 WorkBuddy 授权 Skill 和连接器 → 验证连接并开始任务。

具体下载地址以 README 为准。安装不需要由 WorkBuddy 聊天执行，也不依赖“添加 GitHub 插件市场”界面。

[安装验证及排障](../INSTALL.md) · [授权动图与说明](../resources/OpenGUI-授权指南.html)

## 界面核对说明

2026-10-08 查看 macOS WorkBuddy 5.7.6：技能页的“添加技能”菜单包含查找、上传、创建技能；连接器页的“自定义连接器”打开 MCP 服务管理。本次未发现 Qwen 文档所述的 GitHub 插件市场添加入口，因此不将该流程作为此版本的用户安装步骤。
