# OpenGUI Plugin Support

Use the public [Core-Mate/OpenGUI issue tracker](https://github.com/Core-Mate/OpenGUI/issues) for installation, compatibility, or device-control problems. Include the plugin version, macOS version, Android model/version, connection state from `opengui_list_devices`, and a redacted error message.

Do not attach private phone screenshots, credentials, personal messages, device serials, or proprietary application data. Security-sensitive reports should follow the repository's published security reporting process when one is available; otherwise open a minimal issue asking the maintainers for a private reporting channel.
